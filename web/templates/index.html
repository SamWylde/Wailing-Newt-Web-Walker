Export and import an authentication configuration to enable the crawler to automatically log in to a website for scheduled crawls, or when running from the command line.

⚠️ Warning
Saved authentication data is encrypted securely on your machine, however may still be vulnerable in the event of an attack on your computer.

Import/Export Configuration

Authentication data can be exported securely to a local file of your choosing. These can be imported back in later, or used for scheduled crawls.

Default Configuration

Setting a default configuration will mean this authentication data is loaded in when opening the crawler, and used for all crawls in the absence of a specifically chosen setup.
